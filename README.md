# Newsroom Media Provenance and Verification Support System (MPVSS)
**Systems Analysis & Requirements Engineering — Deliverables #1 & #2**

## 📌 Project Overview
**MPVSS** is a verification workflow and requirements specification designed for a medium-sized digital newsroom[cite: 1]. The platform assists journalists, verification analysts, and managing editors in authenticating raw media assets (photos, video, audio), inspecting embedded metadata (EXIF/IPTC & C2PA Content Credentials), flagging potential deepfakes or manipulations, and compiling tamper-evident audit dossiers for editorial approval and regulatory compliance[cite: 1, 3].

> **Core Principle:** Automated AI-detection scores serve strictly as investigative leads; qualified human journalists and editors retain final publication authority[cite: 19].
